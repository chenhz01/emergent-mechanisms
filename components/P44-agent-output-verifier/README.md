# P44 · agent-output-verifier

> 机制簇：多智能体验证 oracle

## 费曼三层

- **L0（12 岁能懂）**：几个 AI 各给一个答案，交叉比对，找出那个不对劲的。
- **L1（机制本质）**：多数投票得共识，偏离共识者为 outlier。
- **L2（怎么用上）**：verify(outputs) → (consensus, outliers)。

## 运行

```bash
python impl.py
```
