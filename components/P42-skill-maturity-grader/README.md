# P42 · skill-maturity-grader

> 机制簇：技能涌现检测

## 费曼三层

- **L0（12 岁能懂）**：给技能打个成熟度分，知道哪个能放心用。
- **L1（机制本质）**：按 有文档/有测试/有示例 三维加权打分。
- **L2（怎么用上）**：grade(skill) → 0-100。

## 运行

```bash
python impl.py
```
