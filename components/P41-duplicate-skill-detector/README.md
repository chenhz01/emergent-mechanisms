# P41 · duplicate-skill-detector

> 机制簇：技能涌现检测

## 费曼三层

- **L0（12 岁能懂）**：两个技能其实干的是同一件事，留着浪费。这个工具找重复。
- **L1（机制本质）**：Jaccard 相似度超阈值即判近重复。
- **L2（怎么用上）**：dups(skills, thr) → 重复对。

## 运行

```bash
python impl.py
```
