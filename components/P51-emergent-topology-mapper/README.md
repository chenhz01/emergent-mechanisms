# P51 · emergent-topology-mapper

> 机制簇：涌现拓扑/规划/抽象

## 费曼三层

- **L0（12 岁能懂）**：看谁跟谁常联系，画出'谁最能牵线'的关系网。
- **L1（机制本质）**：统计交互频次建图，返回度数最高节点(枢纽)。
- **L2（怎么用上）**：map_graph(interactions) → (hub, edges)。

## 运行

python impl.py
