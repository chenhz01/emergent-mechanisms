# P32 · prm-compute-allocator

> 机制簇：PRM验证器引导计算

## 费曼三层

- **L0（12 岁能懂）**：每步值不值得多想，用'打分员'给分来决定。
- **L1（机制本质）**：按步得分归一化后分配算力预算。
- **L2（怎么用上）**：allocate(scores, budget) → 每步预算。

## 运行

python impl.py
