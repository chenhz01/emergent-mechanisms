# P19 · counterexample-to-lemma-miner

> 机制簇：模糊测试→形式证明

## 费曼三层

- **L0（12 岁能懂）**：一堆反例里藏着规律，这个工具把它们归纳成可复用的'小定理'。
- **L1（机制本质）**：按谓词名聚合反例，生成 lemma 列表。
- **L2（怎么用上）**：mine(cases) 返回 lemma 文本列表。

## 运行

```bash
python impl.py
```
