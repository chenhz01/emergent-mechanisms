# P40 · skill-emergence-scanner

> 机制簇：技能涌现检测

## 费曼三层

- **L0（12 岁能懂）**：代码里反复出现的套路，其实可以打包成一个'技能'。
- **L1（机制本质）**：统计函数名动词前缀频次，频次高的提示可封装技能。
- **L2（怎么用上）**：scan(code) → 候选技能前缀列表。

## 运行

```bash
python impl.py
```
