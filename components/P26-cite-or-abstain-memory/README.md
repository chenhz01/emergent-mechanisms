# P26 · cite-or-abstain-memory

> 机制簇：记忆巩固/溯源

## 费曼三层

- **L0（12 岁能懂）**：没有出处就别硬答，直接说'不知道'，比为编一个更可信。
- **L1（机制本质）**：检索命中且有 source 才回答，否则 ABSTAIN。
- **L2（怎么用上）**：answer(ledger, q) → (text, source) 或 ('ABSTAIN', None)。

python impl.py
