# P55 · causal-discoverer

> 机制簇：涌现拓扑/规划/抽象

## 费曼三层

- **L0（12 岁能懂）**：看两个事件是不是总一起出现，猜它们有没有关系。
- **L1（机制本质）**：条件概率提升度 lift 作为因果候选。
- **L2（怎么用上）**：discover(pairs) → [(a,b,lift)]。

```bash
python impl.py
```
