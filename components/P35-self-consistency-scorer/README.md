# P35 · self-consistency-scorer

> 机制簇：PRM验证器引导计算

## 费曼三层

- **L0（12 岁能懂）**：同一个问题问好几遍，答案多数一致才可信。
- **L1（机制本质）**：多数投票 + 一致率。
- **L2（怎么用上）**：score(answers) → (majority, agreement)。

## 运行

```bash
python impl.py
```
